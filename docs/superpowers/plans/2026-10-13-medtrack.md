# MedTrack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A personal Android app that logs medications (with looked-up ingredients, formula and usage note, photo and notes), rings reliable dose alarms with Taken/Skip/Snooze and history, and optionally triggers reminders from meals logged in Health Connect.

**Architecture:** Single-module native Android app. Pure-Kotlin `schedule/` computes due times; `reminders/` turns them into one exact alarm at a time, using a "scan" model: each wake-up records every dose due since the last scan and books the next wake-up. Room stores medications and dose logs on the device. `lookup/` calls RxNorm, PubChem and MedlinePlus. `health/` polls Health Connect for meals. The Compose UI sits on top, with a hand-written `AppContainer` for dependencies.

**Tech Stack:** Kotlin 2.1.0, AGP 8.9.1, Gradle 8.11.1, Jetpack Compose (BOM 2024.12.01, Material 3), Navigation Compose 2.8.5, Room 2.6.1 (KSP), WorkManager 2.10.0, Health Connect client 1.1.0, kotlinx-serialization-json 1.7.3, JUnit 4 + Robolectric 4.14.1.

**Spec:** `docs/superpowers/specs/2026-10-13-medtrack-design.md`

**Implementation choices within the spec** (all consistent with the approved behaviour):
- The schedule is stored as a JSON column on `medications`, not a separate table. It's still exactly one schedule per medication.
- `dose_logs` gets a `snoozedUntil` column. The 2-hour "missed" clock runs from a dose's last ring (its due time, or the end of a snooze).
- Strengths come from RxNorm clinical-drug names (for example, "pantoprazole 40 MG Oral Tablet" gives "40 MG").

## Review Focus

1. **Phone off or asleep across dose times:** doses are still recorded. Ones due more than 2 h ago become MISSED, recent ones ring on the next wake. Tests: `ReminderPlannerTest.backfillsDosesWhilePhoneWasOff`, `ReminderEngineTest.phoneOffOvernightBackfillsHistory`.
2. **Two medications due in the same minute:** both ring, each actionable on its own. Tests: `ReminderPlannerTest.twoMedicationsSameMinuteBothDue`, `ReminderEngineTest.twoMedicationsSameMinuteBothRing`.
3. **Schedule edited while a dose is pending:** no duplicate pending dose and no orphan alarm. Test: `ReminderEngineTest.editingScheduleKeepsSinglePendingDose`.
4. **Meal logged late, or several meals:** the reminder fires immediately, and only once per day. Tests: `MealCheckerTest.lateMealRingsImmediately`, `MealCheckerTest.secondMealDoesNotAddAnotherDose`.
5. **Partial network failure during lookup:** successful sources are kept, with a status per source. Tests: `MedicationLookupTest.pubchemDownKeepsOtherSources`, `MedicationLookupTest.offlineMarksRxnormFailed`.

```kotlin
import kotlinx.serialization.KSerializer
import kotlinx.serialization.descriptors.PrimitiveKind
import kotlinx.serialization.descriptors.PrimitiveSerialDescriptor
import kotlinx.serialization.encoding.Decoder
import kotlinx.serialization.encoding.Encoder
import java.time.DayOfWeek
import java.time.LocalDate
import java.time.LocalDateTime
import java.time.LocalTime

/** java.time types as ISO strings (DayOfWeek as its enum name). */
abstract class StringSerializer<T : Any>(
    name: String,
    private val format: (T) -> String,
    private val parse: (String) -> T,
) : KSerializer<T> {
    override val descriptor = PrimitiveSerialDescriptor("com.medtrack.$name", PrimitiveKind.STRING)
    override fun serialize(encoder: Encoder, value: T) = encoder.encodeString(format(value))
    override fun deserialize(decoder: Decoder): T = parse(decoder.decodeString())
}

object LocalTimeSerializer : StringSerializer<LocalTime>("LocalTime", LocalTime::toString, LocalTime::parse)
object LocalDateSerializer : StringSerializer<LocalDate>("LocalDate", LocalDate::toString, LocalDate::parse)
object LocalDateTimeSerializer : StringSerializer<LocalDateTime>("LocalDateTime", LocalDateTime::toString, LocalDateTime::parse)
object DayOfWeekSerializer : StringSerializer<DayOfWeek>("DayOfWeek", DayOfWeek::name, DayOfWeek::valueOf)
```

```kotlin
package com.medtrack.schedule

import kotlinx.serialization.SerialName
import kotlinx.serialization.Serializable
import kotlinx.serialization.UseSerializers
import kotlinx.serialization.json.Json
import java.time.DayOfWeek
import java.time.LocalDate
import java.time.LocalDateTime
import java.time.LocalTime

@Serializable
enum class MealType { BREAKFAST, LUNCH, DINNER, ANY }

@Serializable
sealed interface ScheduleRule {
    @Serializable @SerialName("daily")
    data class DailyTimes(val times: List<LocalTime>) : ScheduleRule

    @Serializable @SerialName("weekdays")
    data class Weekdays(val days: Set<DayOfWeek>, val times: List<LocalTime>) : ScheduleRule

    /** Doses every [intervalHours] of elapsed time from [anchor], continuing across days. */
    @Serializable @SerialName("interval")
    data class EveryNHours(val intervalHours: Int, val anchor: LocalDateTime) : ScheduleRule

    /** Fires [delayMinutes] after a matching meal; fires at [fallbackTime] if no meal was logged. */
    @Serializable @SerialName("meal")
    data class AfterMeal(val meal: MealType, val delayMinutes: Int, val fallbackTime: LocalTime) : ScheduleRule
}

@Serializable
data class Schedule(
    val rule: ScheduleRule,
    val startDate: LocalDate,
    val endDate: LocalDate? = null,
)

object ScheduleJson {
    private val json = Json { ignoreUnknownKeys = true }
    fun encode(schedule: Schedule): String = json.encodeToString(Schedule.serializer(), schedule)
    fun decode(text: String): Schedule = json.decodeFromString(Schedule.serializer(), text)
}

/** A user-facing message describing why the schedule can't be saved, or null if it's valid. */
fun Schedule.validationError(): String? {
    if (endDate != null && endDate < startDate) return "End date is before start date"
    return when (val r = rule) {
        is ScheduleRule.DailyTimes -> if (r.times.isEmpty()) "Add at least one time" else null
        is ScheduleRule.Weekdays -> when {
            r.days.isEmpty() -> "Pick at least one day"
            r.times.isEmpty() -> "Add at least one time"
            else -> null
        }
        is ScheduleRule.EveryNHours -> if (r.intervalHours !in 1..24) "Interval must be 1–24 hours" else null
        is ScheduleRule.AfterMeal -> if (r.delayMinutes !in 0..240) "Delay must be 0–240 minutes" else null
    }
}
```

```kotlin
package com.medtrack.schedule

import java.time.DayOfWeek
import java.time.format.DateTimeFormatter
import java.time.format.TextStyle
import java.util.Locale

private val HM = DateTimeFormatter.ofPattern("HH:mm")
private val DAY_MONTH = DateTimeFormatter.ofPattern("d MMM", Locale.ENGLISH)

fun mealName(meal: MealType): String = when (meal) {
    MealType.BREAKFAST -> "breakfast"
    MealType.LUNCH -> "lunch"
    MealType.DINNER -> "dinner"
    MealType.ANY -> "any meal"
}

fun Schedule.describe(): String {
    val base = when (val r = rule) {
        is ScheduleRule.DailyTimes -> "Daily at ${r.times.sorted().joinToString(", ") { it.format(HM) }}"
        is ScheduleRule.Weekdays -> {
            val days = DayOfWeek.values().filter { it in r.days }
                .joinToString(", ") { it.getDisplayName(TextStyle.SHORT, Locale.ENGLISH) }
            "$days at ${r.times.sorted().joinToString(", ") { it.format(HM) }}"
        }
        is ScheduleRule.EveryNHours -> "Every ${r.intervalHours} h from ${r.anchor.toLocalTime().format(HM)}"
        is ScheduleRule.AfterMeal -> {
            val delay = if (r.delayMinutes == 0) "Right" else "${r.delayMinutes} min"
            "$delay after ${mealName(r.meal)} (by ${r.fallbackTime.format(HM)})"
        }
    }
    return if (endDate != null) "$base, until ${endDate.format(DAY_MONTH)}" else base
}
```

```kotlin
package com.medtrack.schedule

import java.time.Duration
import java.time.Instant
import java.time.LocalDate
import java.time.LocalTime
import java.time.ZoneId

/** Upper bound on days searched, so a schedule whose dates are all skipped can't loop forever. */
private const val MAX_DAYS = 400

/**
 * The first dose strictly after [after], or null when the schedule has no more doses.
 * Doses whose local date is in [skipDates] are skipped. For [ScheduleRule.AfterMeal]
 * this is the fallback time; meal-triggered doses come from [mealTriggeredDose].
 */
fun nextDose(schedule: Schedule, after: Instant, zone: ZoneId, skipDates: Set<LocalDate> = emptySet()): Instant? =
    when (val rule = schedule.rule) {
        is ScheduleRule.DailyTimes -> nextOnDays(schedule, after, zone, skipDates, rule.times) { true }
        is ScheduleRule.Weekdays -> nextOnDays(schedule, after, zone, skipDates, rule.times) { it.dayOfWeek in rule.days }
        is ScheduleRule.AfterMeal -> nextOnDays(schedule, after, zone, skipDates, listOf(rule.fallbackTime)) { true }
        is ScheduleRule.EveryNHours -> nextInterval(schedule, rule, after, zone, skipDates)
    }

/** All doses in (from, to]. */
fun dosesBetween(
    schedule: Schedule,
    from: Instant,
    to: Instant,
    zone: ZoneId,
    skipDates: Set<LocalDate> = emptySet(),
): List<Instant> = buildList {
    var cursor = from
    while (true) {
        val next = nextDose(schedule, cursor, zone, skipDates) ?: break
        if (next > to) break
        add(next)
        cursor = next
    }
}

private fun nextOnDays(
    schedule: Schedule,
    after: Instant,
    zone: ZoneId,
    skipDates: Set<LocalDate>,
    times: List<LocalTime>,
    dayAllowed: (LocalDate) -> Boolean,
): Instant? {
    if (times.isEmpty()) return null
    val sorted = times.sorted()
    var date = maxOf(after.atZone(zone).toLocalDate(), schedule.startDate)
    repeat(MAX_DAYS) {
        if (schedule.endDate != null && date > schedule.endDate) return null
        if (dayAllowed(date) && date !in skipDates) {
            for (time in sorted) {
                // atZone moves times in a DST gap forward and picks the earlier offset in an overlap.
                val candidate = date.atTime(time).atZone(zone).toInstant()
                if (candidate > after) return candidate
            }
        }
        date = date.plusDays(1)
    }
    return null
}

private fun nextInterval(
    schedule: Schedule,
    rule: ScheduleRule.EveryNHours,
    after: Instant,
    zone: ZoneId,
    skipDates: Set<LocalDate>,
): Instant? {
    if (rule.intervalHours <= 0) return null
    val anchor = rule.anchor.atZone(zone).toInstant()
    val step = Duration.ofHours(rule.intervalHours.toLong())
    var k = if (after < anchor) 0L else Duration.between(anchor, after).toMillis() / step.toMillis() + 1
    repeat(MAX_DAYS * 24) {
        val candidate = anchor.plus(step.multipliedBy(k))
        val date = candidate.atZone(zone).toLocalDate()
        if (schedule.endDate != null && date > schedule.endDate) return null
        if (date >= schedule.startDate && date !in skipDates) return candidate
        k++
    }
    return null
}
```

```kotlin
package com.medtrack.schedule

import java.time.Duration
import java.time.Instant
import java.time.LocalDate
import java.time.ZoneId

/** A meal read from Health Connect. [type] is null for snacks and unknown meals. */
data class Meal(val time: Instant, val type: MealType?)

/**
 * When an after-meal dose should ring today: the earliest matching meal today plus the delay.
 * Null when today already has a dose ([handledDates]), the course isn't running today,
 * no meal matches, or the schedule isn't after-meal.
 */
fun mealTriggeredDose(
    schedule: Schedule,
    meals: List<Meal>,
    today: LocalDate,
    zone: ZoneId,
    handledDates: Set<LocalDate>,
): Instant? {
    val rule = schedule.rule as? ScheduleRule.AfterMeal ?: return null
    if (today in handledDates) return null
    if (today < schedule.startDate || (schedule.endDate != null && today > schedule.endDate)) return null
    val meal = meals
        .filter { it.time.atZone(zone).toLocalDate() == today }
        .filter { rule.meal == MealType.ANY || it.type == rule.meal }
        .minByOrNull { it.time } ?: return null
    return meal.time.plus(Duration.ofMinutes(rule.delayMinutes.toLong()))
}
```

```kotlin
package com.medtrack.data

import android.content.Context
import android.graphics.Bitmap
import android.graphics.BitmapFactory
import android.graphics.Matrix
import android.net.Uri
import androidx.exifinterface.media.ExifInterface
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.withContext
import java.io.File
import java.io.FileOutputStream
import java.util.UUID
import kotlin.math.roundToInt

/** Copies chosen photos into app-private storage, resized, so the original can be deleted safely. */
class PhotoStore(private val context: Context) {
    val photosDir: File get() = File(context.filesDir, "photos").apply { mkdirs() }

    suspend fun importFrom(uri: Uri): String = withContext(Dispatchers.IO) {
        val resolver = context.contentResolver
        val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
        resolver.openInputStream(uri).use { BitmapFactory.decodeStream(it, null, bounds) }
        require(bounds.outWidth > 0 && bounds.outHeight > 0) { "Not an image" }

        val options = BitmapFactory.Options().apply { inSampleSize = sampleSizeFor(bounds.outWidth, bounds.outHeight, MAX_SIDE) }
        val decoded = resolver.openInputStream(uri).use { BitmapFactory.decodeStream(it, null, options) }
            ?: error("Could not decode image")
        val rotation = resolver.openInputStream(uri).use { stream -> stream?.let { ExifInterface(it).rotationDegrees } ?: 0 }

        val (w, h) = scaledSize(decoded.width, decoded.height, MAX_SIDE)
        var bitmap = if (w != decoded.width || h != decoded.height) Bitmap.createScaledBitmap(decoded, w, h, true) else decoded
        if (rotation != 0) {
            val matrix = Matrix().apply { postRotate(rotation.toFloat()) }
            bitmap = Bitmap.createBitmap(bitmap, 0, 0, bitmap.width, bitmap.height, matrix, true)
        }
        val file = File(photosDir, "${UUID.randomUUID()}.jpg")
        FileOutputStream(file).use { bitmap.compress(Bitmap.CompressFormat.JPEG, 85, it) }
        file.absolutePath
    }

    fun delete(path: String?) {
        val file = path?.let(::File) ?: return
        if (file.parentFile?.absolutePath == photosDir.absolutePath) file.delete()
    }

    companion object {
        const val MAX_SIDE = 1200

        /** Largest power-of-two subsampling that keeps the longest side at or above [maxSide]. */
        fun sampleSizeFor(width: Int, height: Int, maxSide: Int): Int {
            var sample = 1
            while (maxOf(width, height) / (sample * 2) >= maxSide) sample *= 2
            return sample
        }

        fun scaledSize(width: Int, height: Int, maxSide: Int): Pair<Int, Int> {
            val longest = maxOf(width, height)
            if (longest <= maxSide) return width to height
            val factor = maxSide.toDouble() / longest
            return (width * factor).roundToInt().coerceAtLeast(1) to (height * factor).roundToInt().coerceAtLeast(1)
        }

        fun decodeSampled(path: String, maxSide: Int): Bitmap? {
            val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
            BitmapFactory.decodeFile(path, bounds)
            if (bounds.outWidth <= 0) return null
            val options = BitmapFactory.Options().apply { inSampleSize = sampleSizeFor(bounds.outWidth, bounds.outHeight, maxSide) }
            return BitmapFactory.decodeFile(path, options)
        }
    }
}
```

```kotlin
package com.medtrack.data

/** Writes to medications, then runs [onChanged] so reminders are rebuilt. */
class MedicationRepository(
    private val dao: MedicationDao,
    private val photos: PhotoStore,
    private val onChanged: suspend () -> Unit,
) {
    suspend fun save(medication: MedicationEntity): Long {
        val id = if (medication.id == 0L) dao.insert(medication) else medication.id.also { dao.update(medication) }
        onChanged()
        return id
    }

    suspend fun setActive(id: Long, active: Boolean) {
        dao.setActive(id, active)
        onChanged()
    }

    suspend fun delete(id: Long) {
        val medication = dao.get(id) ?: return
        dao.delete(medication)
        photos.delete(medication.photoPath)
        onChanged()
    }
}
```

```kotlin
package com.medtrack.lookup

import kotlinx.serialization.json.Json
import kotlinx.serialization.json.JsonArray
import kotlinx.serialization.json.JsonElement
import kotlinx.serialization.json.JsonObject
import kotlinx.serialization.json.JsonPrimitive

data class Suggestion(val rxcui: String, val name: String)

data class RelatedConcepts(val ingredients: List<Suggestion>, val clinicalDrugNames: List<String>)

private val json = Json { ignoreUnknownKeys = true }

private fun parse(body: String): JsonObject? = json.parseToJsonElement(body) as? JsonObject
private fun JsonElement?.obj(key: String): JsonElement? = (this as? JsonObject)?.get(key)
private fun JsonElement?.array(key: String): List<JsonElement> = (obj(key) as? JsonArray).orEmpty()
private fun JsonElement?.str(key: String): String? = (obj(key) as? JsonPrimitive)?.takeIf { it.isString }?.content

/** RxNorm approximateTerm: one suggestion per rxcui, preferring the RxNorm-sourced name. */
internal fun parseSuggestions(body: String): List<Suggestion> {
    val byRxcui = LinkedHashMap<String, MutableList<JsonElement>>()
    parse(body).obj("approximateGroup").array("candidate").forEach { candidate ->
        val rxcui = candidate.str("rxcui") ?: return@forEach
        byRxcui.getOrPut(rxcui) { mutableListOf() } += candidate
    }
    return byRxcui.mapNotNull { (rxcui, candidates) ->
        val name = candidates.firstOrNull { it.str("source") == "RXNORM" }?.str("name")
            ?: candidates.firstNotNullOfOrNull { it.str("name") }
            ?: return@mapNotNull null
        Suggestion(rxcui, name.lowercase())
    }
}

internal fun parseRxcui(body: String): String? =
    (parse(body).obj("idGroup").array("rxnormId").firstOrNull() as? JsonPrimitive)?.content

internal fun parseRelated(body: String): RelatedConcepts {
    val groups = parse(body).obj("relatedGroup").array("conceptGroup")
    fun concepts(tty: String) = groups.filter { it.str("tty") == tty }.flatMap { it.array("conceptProperties") }
    return RelatedConcepts(
        ingredients = concepts("IN").mapNotNull { c ->
            val rxcui = c.str("rxcui")
            val name = c.str("name")
            if (rxcui != null && name != null) Suggestion(rxcui, name) else null
        },
        clinicalDrugNames = concepts("SCD").mapNotNull { it.str("name") },
    )
}

private const val UNIT = """(?:MG|MCG|G|ML|UNT|MEQ|%)(?:/(?:ML|MG|ACTUAT|HR|G))?"""

/** Strengths of [ingredient] found in clinical drug names such as "acetaminophen 450 MG / caffeine 30 MG Oral Tablet". */
internal fun parseStrengths(ingredient: String, clinicalDrugNames: List<String>): String? {
    val pattern = Regex("""(?:^|\s)${Regex.escape(ingredient)} ([\d.]+ $UNIT)""", RegexOption.IGNORE_CASE)
    val found = clinicalDrugNames
        .flatMap { name -> pattern.findAll(name).map { it.groupValues[1].uppercase() }.toList() }
        .distinct()
    if (found.isEmpty()) return null
    return found
        .sortedWith(compareBy<String>({ it.substringAfter(' ') }, { it.substringBefore(' ').toDoubleOrNull() ?: 0.0 }))
        .joinToString(", ")
}

internal fun parseFormula(body: String): String? =
    parse(body).obj("PropertyTable").array("Properties").firstOrNull().str("MolecularFormula")

internal fun parseMedlineSummary(body: String): String? {
    val raw = parse(body).obj("feed").array("entry")
        .firstNotNullOfOrNull { it.obj("summary").str("_value")?.takeIf(String::isNotBlank) }
        ?: return null
    return shortSummary(raw)
}

/** Strips HTML and keeps the first two sentences, capped at [maxChars]. */
internal fun shortSummary(html: String, maxChars: Int = 300): String {
    val text = html
        .replace(Regex("<[^>]+>"), " ")
        .replace("&nbsp;", " ")
        .replace("&amp;", "&")
        .replace(Regex("\\s+"), " ")
        .trim()
    val twoSentences = text.split(Regex("(?<=[.!?])\\s+")).take(2).joinToString(" ")
    return if (twoSentences.length <= maxChars) twoSentences
    else twoSentences.take(maxChars).substringBeforeLast(' ') + "…"
}
```

```kotlin
package com.medtrack.lookup

import com.medtrack.data.Ingredient
import com.medtrack.data.SourceStatus
import kotlinx.coroutines.CancellationException
import java.io.IOException
import java.net.URLEncoder

data class LookupResult(
    val rxcui: String? = null,
    val ingredients: List<Ingredient> = emptyList(),
    val usedFor: String? = null,
    val rxnorm: SourceStatus = SourceStatus.NOT_RUN,
    val pubchem: SourceStatus = SourceStatus.NOT_RUN,
    val medline: SourceStatus = SourceStatus.NOT_RUN,
)

/** Looks a generic name up in RxNorm, then PubChem (formula per ingredient), then MedlinePlus (usage). */
class MedicationLookup(private val fetch: Fetch) {

    suspend fun suggest(term: String): List<Suggestion> = try {
        getOrNull("$RXNAV/approximateTerm.json?term=${enc(term)}&maxEntries=8")?.let(::parseSuggestions).orEmpty()
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        emptyList()
    }

    /** Runs the sources in order. [onProgress] receives the cumulative result after each one. */
    suspend fun lookup(
        name: String,
        knownRxcui: String? = null,
        onProgress: (LookupResult) -> Unit = {},
    ): LookupResult {
        var result = LookupResult()
        var ingredientRxcuis: List<String> = emptyList()
        try {
            val rxcui = knownRxcui ?: getOrNull("$RXNAV/rxcui.json?name=${enc(name)}&search=2")?.let(::parseRxcui)
            if (rxcui == null) return result.copy(rxnorm = SourceStatus.NOT_FOUND).also(onProgress)
            val related = getOrNull("$RXNAV/rxcui/$rxcui/related.json?tty=IN+SCD")?.let(::parseRelated)
                ?: RelatedConcepts(emptyList(), emptyList())
            val ingredients = related.ingredients.ifEmpty { listOf(Suggestion(rxcui, name.trim().lowercase())) }
            ingredientRxcuis = ingredients.map { it.rxcui }
            result = result.copy(
                rxcui = rxcui,
                rxnorm = SourceStatus.OK,
                ingredients = ingredients.map { Ingredient(it.name, parseStrengths(it.name, related.clinicalDrugNames)) },
            )
            onProgress(result)
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            return result.copy(rxnorm = SourceStatus.FAILED).also(onProgress)
        }

        result = withFormulas(result)
        onProgress(result)
        result = withUsedFor(result, listOf(result.rxcui!!) + ingredientRxcuis)
        onProgress(result)
        return result
    }

    private suspend fun withFormulas(result: LookupResult): LookupResult {
        var found = false
        var failed = false
        val ingredients = result.ingredients.map { ingredient ->
            try {
                val formula = getOrNull("$PUBCHEM/compound/name/${encPath(ingredient.name)}/property/MolecularFormula/JSON")
                    ?.let(::parseFormula)
                if (formula != null) found = true
                ingredient.copy(formula = formula)
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                failed = true
                ingredient
            }
        }
        val status = when {
            found -> SourceStatus.OK
            failed -> SourceStatus.FAILED
            else -> SourceStatus.NOT_FOUND
        }
        return result.copy(ingredients = ingredients, pubchem = status)
    }

    private suspend fun withUsedFor(result: LookupResult, rxcuis: List<String>): LookupResult = try {
        val summary = rxcuis.distinct().firstNotNullOfOrNull { id ->
            getOrNull("$MEDLINE?mainSearchCriteria.v.cs=2.16.840.1.113883.6.88&mainSearchCriteria.v.c=$id&knowledgeResponseType=application/json")
                ?.let(::parseMedlineSummary)
        }
        if (summary != null) result.copy(usedFor = summary, medline = SourceStatus.OK)
        else result.copy(medline = SourceStatus.NOT_FOUND)
    } catch (e: CancellationException) {
        throw e
    } catch (e: Exception) {
        result.copy(medline = SourceStatus.FAILED)
    }

    /** Body for 2xx, null for 404, IOException for anything else. */
    private suspend fun getOrNull(url: String): String? {
        val response = fetch(url)
        return when {
            response.code in 200..299 -> response.body
            response.code == 404 -> null
            else -> throw IOException("HTTP ${response.code} for $url")
        }
    }

    private fun enc(text: String) = URLEncoder.encode(text.trim(), "UTF-8")
    private fun encPath(text: String) = enc(text).replace("+", "%20")

    private companion object {
        const val RXNAV = "https://rxnav.nlm.nih.gov/REST"
        const val PUBCHEM = "https://pubchem.ncbi.nlm.nih.gov/rest/pug"
        const val MEDLINE = "https://connect.medlineplus.gov/service"
    }
}
```

```kotlin
package com.medtrack.lookup

import com.medtrack.data.MedicationEntity
import com.medtrack.data.SourceStatus

/**
 * Copies looked-up fields onto the medication. Sources that haven't run are ignored.
 * With [onlyMissing], sources already OK on the medication are left alone (a retry keeps the user's edits).
 * A failed or not-found source only updates its status; existing field values are kept.
 */
fun MedicationEntity.applyLookup(result: LookupResult, onlyMissing: Boolean): MedicationEntity {
    fun take(current: SourceStatus, incoming: SourceStatus) =
        incoming != SourceStatus.NOT_RUN && !(onlyMissing && current == SourceStatus.OK)

    var m = this
    if (take(m.rxnormStatus, result.rxnorm)) {
        m = if (result.rxnorm == SourceStatus.OK) {
            m.copy(rxcui = result.rxcui, ingredients = result.ingredients, rxnormStatus = SourceStatus.OK)
        } else {
            m.copy(rxnormStatus = result.rxnorm)
        }
    }
    if (take(m.pubchemStatus, result.pubchem)) {
        m = if (result.pubchem == SourceStatus.OK) {
            val formulas = result.ingredients.associate { it.name.lowercase() to it.formula }
            m.copy(
                ingredients = m.ingredients.map { i -> formulas[i.name.lowercase()]?.let { i.copy(formula = it) } ?: i },
                pubchemStatus = SourceStatus.OK,
            )
        } else {
            m.copy(pubchemStatus = result.pubchem)
        }
    }
    if (take(m.medlineStatus, result.medline)) {
        m = if (result.medline == SourceStatus.OK) {
            m.copy(usedFor = result.usedFor, medlineStatus = SourceStatus.OK)
        } else {
            m.copy(medlineStatus = result.medline)
        }
    }
    return m
}
```

  - `data class MedSchedule(val medicationId: Long, val schedule: Schedule)`
  - `data class PendingDose(val logId: Long, val medicationId: Long, val dueAt: Instant, val snoozedUntil: Instant?)`
  - `data class NewDose(val medicationId: Long, val dueAt: Instant, val trigger: DoseTrigger)`
  - `data class ScanPlan(newDoses: List<NewDose>, missedDoses: List<NewDose>, missedLogIds: List<Long>, ringLogIds: List<Long>, nextWake: Instant?)`
  - `fun planScan(meds: List<MedSchedule>, handledDates: Map<Long, Set<LocalDate>>, pending: List<PendingDose>, lastScanAt: Instant, now: Instant, zone: ZoneId): ScanPlan`

**Rules** (the engine relies on these):
- Scheduled doses in `(max(lastScanAt, now − 7 d), now]` become `newDoses` (to insert as PENDING and ring). Ones due at or before `now − 2 h` become `missedDoses` instead. After-meal fallbacks skip dates in `handledDates` and use trigger FALLBACK; everything else uses SCHEDULE.
- For each pending dose, `ringAt = snoozedUntil ?: dueAt`. If `ringAt ≤ now − 2 h` it goes to `missedLogIds`. Otherwise, if `ringAt` is in `(lastScanAt, now]`, it goes to `ringLogIds`.
- `nextWake` is the earliest future instant among: each medication's next dose, each pending dose's `ringAt` (if it's in the future) or `ringAt + 2 h`, and each new dose's `dueAt + 2 h`.

```kotlin
package com.medtrack.reminders

import com.medtrack.data.DoseTrigger
import com.medtrack.schedule.Schedule
import com.medtrack.schedule.ScheduleRule
import com.medtrack.schedule.dosesBetween
import com.medtrack.schedule.nextDose
import java.time.Duration
import java.time.Instant
import java.time.LocalDate
import java.time.ZoneId

val MISSED_AFTER: Duration = Duration.ofHours(2)
val SNOOZE_FOR: Duration = Duration.ofMinutes(10)
private val MAX_BACKFILL: Duration = Duration.ofDays(7)

data class MedSchedule(val medicationId: Long, val schedule: Schedule)
data class PendingDose(val logId: Long, val medicationId: Long, val dueAt: Instant, val snoozedUntil: Instant?)
data class NewDose(val medicationId: Long, val dueAt: Instant, val trigger: DoseTrigger)

data class ScanPlan(
    /** Insert as PENDING and ring. */
    val newDoses: List<NewDose>,
    /** Due while the phone couldn't ring, more than [MISSED_AFTER] ago: insert as MISSED. */
    val missedDoses: List<NewDose>,
    /** Existing PENDING logs to mark MISSED. */
    val missedLogIds: List<Long>,
    /** Existing PENDING logs whose ring time (due or snooze end) has just arrived. */
    val ringLogIds: List<Long>,
    /** When to wake next, or null if nothing is scheduled. */
    val nextWake: Instant?,
)

/** Decides what a wake-up at [now] must record, ring and schedule, given the previous wake-up at [lastScanAt]. */
fun planScan(
    meds: List<MedSchedule>,
    handledDates: Map<Long, Set<LocalDate>>,
    pending: List<PendingDose>,
    lastScanAt: Instant,
    now: Instant,
    zone: ZoneId,
): ScanPlan {
    val from = maxOf(lastScanAt, now.minus(MAX_BACKFILL))
    val missedCutoff = now.minus(MISSED_AFTER)
    val newDoses = mutableListOf<NewDose>()
    val missedDoses = mutableListOf<NewDose>()
    val wakes = mutableListOf<Instant>()

    for (med in meds) {
        val isMeal = med.schedule.rule is ScheduleRule.AfterMeal
        val skip = if (isMeal) handledDates[med.medicationId].orEmpty() else emptySet()
        val trigger = if (isMeal) DoseTrigger.FALLBACK else DoseTrigger.SCHEDULE
        for (due in dosesBetween(med.schedule, from, now, zone, skip)) {
            val dose = NewDose(med.medicationId, due, trigger)
            if (due <= missedCutoff) missedDoses += dose else {
                newDoses += dose
                wakes += due.plus(MISSED_AFTER)
            }
        }
        nextDose(med.schedule, now, zone, skip)?.let { wakes += it }
    }

    val missedLogIds = mutableListOf<Long>()
    val ringLogIds = mutableListOf<Long>()
    for (dose in pending) {
        val ringAt = dose.snoozedUntil ?: dose.dueAt
        if (ringAt <= missedCutoff) {
            missedLogIds += dose.logId
            continue
        }
        if (ringAt > lastScanAt && ringAt <= now) ringLogIds += dose.logId
        wakes += if (ringAt > now) ringAt else ringAt.plus(MISSED_AFTER)
    }

    return ScanPlan(newDoses, missedDoses, missedLogIds, ringLogIds, wakes.filter { it > now }.minOrNull())
}
```

```kotlin
package com.medtrack.reminders

import android.app.AlarmManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.os.Build
import com.medtrack.MainActivity
import java.time.Instant

/** Holds the app's single wake-up alarm. */
class AlarmScheduler(private val context: Context) {
    private val alarmManager = context.getSystemService(AlarmManager::class.java)

    fun canScheduleExact(): Boolean =
        Build.VERSION.SDK_INT < Build.VERSION_CODES.S || alarmManager.canScheduleExactAlarms()

    fun set(at: Instant?) {
        val operation = PendingIntent.getBroadcast(
            context, 0, Intent(context, AlarmReceiver::class.java),
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )
        if (at == null) {
            alarmManager.cancel(operation)
            return
        }
        if (canScheduleExact()) {
            // Alarm-clock alarms are exempt from Doze and survive aggressive OEM battery savers best.
            val show = PendingIntent.getActivity(context, 0, Intent(context, MainActivity::class.java), PendingIntent.FLAG_IMMUTABLE)
            alarmManager.setAlarmClock(AlarmManager.AlarmClockInfo(at.toEpochMilli(), show), operation)
        } else {
            // Degraded: may ring late. Settings and Today show a warning until exact alarms are allowed.
            alarmManager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at.toEpochMilli(), operation)
        }
    }
}
```

```kotlin
        items.forEachIndexed { index, item ->
            val notification = NotificationCompat.Builder(context, CHANNEL_ID)
                .setSmallIcon(R.drawable.ic_pill)
                .setContentTitle(item.title)
                .setContentText(item.text.ifBlank { "Time to take your medication" })
                .setStyle(NotificationCompat.BigTextStyle().bigText(item.text.ifBlank { "Time to take your medication" }))

                .setCategory(NotificationCompat.CATEGORY_ALARM)

                .setVisibility(NotificationCompat.VISIBILITY_PUBLIC)

                .setContentIntent(alarmScreen())
                .setFullScreenIntent(alarmScreen(), true)

                .addAction(0, "Skip", action(item.logId, DoseActionReceiver.ACTION_SKIP, 2))
                .addAction(0, "Snooze 10 min", action(item.logId, DoseActionReceiver.ACTION_SNOOZE, 3))
                .build()
            if (index == 0) notification.flags = notification.flags or Notification.FLAG_INSISTENT // repeat sound until acted on
            manager.notify(TAG, item.logId.toInt(), notification)
        }

            val summary = NotificationCompat.Builder(context, CHANNEL_ID)
                .setSmallIcon(R.drawable.ic_pill)
                .setContentTitle("${items.size} medications due")
                .setGroup(GROUP)
                .setGroupSummary(true)
                .setSilent(true)
                .setContentIntent(alarmScreen())

    )

        const val CHANNEL_ID = "dose_alarms_v1"
        const val TAG = "dose"
        private const val SUMMARY_TAG = "dose_summary"
        private const val GROUP = "doses"
    }
```

```kotlin
package com.medtrack.reminders

import com.medtrack.data.AppPrefs
import com.medtrack.data.DoseLogDao
import com.medtrack.data.DoseLogEntity
import com.medtrack.data.DoseStatus
import com.medtrack.data.DoseTrigger
import com.medtrack.data.MedicationDao
import com.medtrack.data.displayName
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import java.time.Clock
import java.time.Duration
import java.time.Instant
import java.time.temporal.ChronoUnit

/**
 * Owns dose logs, notifications and the wake-up alarm. Every entry point ends with a scan,
 * so the stored state, the visible notifications and the next alarm always agree.
 */
class ReminderEngine(
    private val medications: MedicationDao,
    private val doseLogs: DoseLogDao,
    private val alarms: AlarmScheduler,
    private val notifier: DoseNotifier,
    private val prefs: AppPrefs,
    private val clock: () -> Clock = { Clock.systemDefaultZone() },
) {
    private val mutex = Mutex()

    private fun now(): Instant = clock().instant().truncatedTo(ChronoUnit.MILLIS)

    suspend fun sync() = mutex.withLock { scan() }

    suspend fun markTaken(logId: Long) = setStatus(listOf(logId), DoseStatus.TAKEN)
    suspend fun markSkipped(logId: Long) = setStatus(listOf(logId), DoseStatus.SKIPPED)
    suspend fun markAllTaken(logIds: List<Long>) = setStatus(logIds, DoseStatus.TAKEN)

    suspend fun snooze(logId: Long) = mutex.withLock {
        doseLogs.snooze(logId, now().plus(SNOOZE_FOR))
        notifier.cancel(logId)
        scan()
    }

    /** Taken/skipped from the Today screen before the dose rang; stops it ringing later. */
    suspend fun recordUpcoming(medicationId: Long, dueAt: Instant, status: DoseStatus) = mutex.withLock {
        doseLogs.insertIgnore(
            DoseLogEntity(medicationId = medicationId, dueAt = dueAt, status = status, trigger = DoseTrigger.SCHEDULE, actedAt = now()),
        )
        scan()
    }

    /** A meal was detected: add the dose (it also marks today as handled for the fallback). */
    suspend fun addMealDose(medicationId: Long, dueAt: Instant) = mutex.withLock {
        val id = doseLogs.insertIgnore(
            DoseLogEntity(medicationId = medicationId, dueAt = dueAt, status = DoseStatus.PENDING, trigger = DoseTrigger.MEAL),
        )
        scan(ringNow = if (id > 0 && dueAt <= now()) listOf(id) else emptyList())
    }

    private suspend fun setStatus(logIds: List<Long>, status: DoseStatus) = mutex.withLock {
        val at = now()
        logIds.forEach {
            doseLogs.setStatus(it, status, at)
            notifier.cancel(it)
        }
        scan()
    }

    private suspend fun scan(ringNow: List<Long> = emptyList()) {
        val c = clock()
        val now = now()
        val zone = c.zone
        val lastScan = prefs.lastScanAt ?: now
        val meds = medications.active()
        val recent = doseLogs.since(minOf(lastScan, now).minus(Duration.ofDays(8)))
        val handled = recent.groupBy { it.medicationId }
            .mapValues { (_, logs) -> logs.map { it.dueAt.atZone(zone).toLocalDate() }.toSet() }

        val plan = planScan(
            meds = meds.map { MedSchedule(it.id, it.schedule) },
            handledDates = handled,
            pending = doseLogs.pending().map { PendingDose(it.id, it.medicationId, it.dueAt, it.snoozedUntil) },
            lastScanAt = lastScan,
            now = now,
            zone = zone,
        )

        val inserted = plan.newDoses.map {
            doseLogs.insertIgnore(DoseLogEntity(medicationId = it.medicationId, dueAt = it.dueAt, status = DoseStatus.PENDING, trigger = it.trigger))
        }.filter { it > 0 }
        plan.missedDoses.forEach {
            doseLogs.insertIgnore(DoseLogEntity(medicationId = it.medicationId, dueAt = it.dueAt, status = DoseStatus.MISSED, trigger = it.trigger))
        }
        if (plan.missedLogIds.isNotEmpty()) doseLogs.markMissed(plan.missedLogIds)
        prefs.lastScanAt = now

        notifier.cancelAllExcept(doseLogs.pending().map { it.id }.toSet())
        val ring = doseLogs.byIds((inserted + plan.ringLogIds + ringNow).distinct()).filter { it.status == DoseStatus.PENDING }
        if (ring.isNotEmpty()) {
            val medsById = medications.byIds(ring.map { it.medicationId }.distinct()).associateBy { it.id }
            notifier.ring(
                ring.sortedBy { it.dueAt }.mapNotNull { log ->
                    medsById[log.medicationId]?.let { med ->
                        RingItem(log.id, med.displayName(), listOfNotNull(med.doseText, med.notes).filter { it.isNotBlank() }.joinToString(" · "), med.photoPath)
                    }
                },
            )
        }
        alarms.set(plan.nextWake)
    }
}
```

```kotlin
package com.medtrack.health

import com.medtrack.data.DoseLogDao
import com.medtrack.data.MedicationDao
import com.medtrack.reminders.ReminderEngine
import com.medtrack.schedule.Meal
import com.medtrack.schedule.ScheduleRule
import com.medtrack.schedule.mealTriggeredDose
import java.time.Clock
import java.time.Instant
import java.time.LocalDate

/** Turns today's logged meals into after-meal doses. [readMeals] returns null when meals can't be read. */
class MealChecker(
    private val readMeals: suspend (from: Instant, to: Instant) -> List<Meal>?,
    private val medications: MedicationDao,
    private val doseLogs: DoseLogDao,
    private val engine: ReminderEngine,
    private val clock: () -> Clock = { Clock.systemDefaultZone() },
) {
    suspend fun check() {
        val c = clock()
        val now = c.instant()
        val zone = c.zone
        val today = LocalDate.now(c)
        val mealMeds = medications.active().filter { it.schedule.rule is ScheduleRule.AfterMeal }
        if (mealMeds.isEmpty()) return
        val dayStart = today.atStartOfDay(zone).toInstant()
        val meals = readMeals(dayStart, now) ?: return
        val handledToday = doseLogs.since(dayStart)
            .filter { it.dueAt.atZone(zone).toLocalDate() == today }
            .map { it.medicationId }
            .toSet()
        for (med in mealMeds) {
            val handled = if (med.id in handledToday) setOf(today) else emptySet()
            val due = mealTriggeredDose(med.schedule, meals, today, zone, handled) ?: continue
            engine.addMealDose(med.id, maxOf(due, now))
        }
    }
}
```

```kotlin
package com.medtrack.health

import android.content.Context
import androidx.health.connect.client.HealthConnectClient
import androidx.health.connect.client.HealthConnectFeatures
import androidx.health.connect.client.permission.HealthPermission
import androidx.health.connect.client.records.NutritionRecord
import androidx.health.connect.client.request.ReadRecordsRequest
import androidx.health.connect.client.time.TimeRangeFilter
import com.medtrack.schedule.Meal
import com.medtrack.schedule.MealType
import java.time.Instant
import androidx.health.connect.client.records.MealType as HcMealType

enum class HealthStatus { NOT_INSTALLED, NEEDS_UPDATE, NO_BACKGROUND_READ, NOT_CONNECTED, CONNECTED }

class HealthConnectGateway(private val context: Context) {
    val permissions: Set<String> = setOf(
        HealthPermission.getReadPermission(NutritionRecord::class),
        HealthPermission.PERMISSION_READ_HEALTH_DATA_IN_BACKGROUND,
    )

    suspend fun status(): HealthStatus {
        when (HealthConnectClient.getSdkStatus(context)) {
            HealthConnectClient.SDK_UNAVAILABLE -> return HealthStatus.NOT_INSTALLED
            HealthConnectClient.SDK_UNAVAILABLE_PROVIDER_UPDATE_REQUIRED -> return HealthStatus.NEEDS_UPDATE
        }
        val client = HealthConnectClient.getOrCreate(context)
        val background = client.features.getFeatureStatus(HealthConnectFeatures.FEATURE_READ_HEALTH_DATA_IN_BACKGROUND)
        if (background != HealthConnectFeatures.FEATURE_STATUS_AVAILABLE) return HealthStatus.NO_BACKGROUND_READ
        val granted = client.permissionController.getGrantedPermissions()
        return if (granted.containsAll(permissions)) HealthStatus.CONNECTED else HealthStatus.NOT_CONNECTED
    }

    suspend fun mealsBetween(from: Instant, to: Instant): List<Meal>? {
        if (status() != HealthStatus.CONNECTED) return null
        val client = HealthConnectClient.getOrCreate(context)
        val response = client.readRecords(ReadRecordsRequest(NutritionRecord::class, TimeRangeFilter.between(from, to)))
        return response.records.map { Meal(it.startTime, it.mealType.toMealType()) }
    }
}

private fun Int.toMealType(): MealType? = when (this) {
    HcMealType.MEAL_TYPE_BREAKFAST -> MealType.BREAKFAST
    HcMealType.MEAL_TYPE_LUNCH -> MealType.LUNCH
    HcMealType.MEAL_TYPE_DINNER -> MealType.DINNER
    else -> null // snack or unknown
```

```kotlin
package com.medtrack.health

import android.content.Context
import android.util.Log
import androidx.work.CoroutineWorker
import androidx.work.ExistingPeriodicWorkPolicy
import androidx.work.PeriodicWorkRequestBuilder
import androidx.work.WorkManager
import androidx.work.WorkerParameters
import com.medtrack.container
import kotlinx.coroutines.CancellationException
import java.util.concurrent.TimeUnit

class MealCheckWorker(context: Context, params: WorkerParameters) : CoroutineWorker(context, params) {
    override suspend fun doWork(): Result {
        try {
            applicationContext.container.mealChecker.check()
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            // e.g. permission revoked mid-read; the fallback alarm still covers the dose.
            Log.w("MealCheckWorker", "Meal check failed", e)
        }
        return Result.success()
    }
}

/** Runs [MealCheckWorker] every 15 minutes (Android's minimum) while any after-meal medication is active. */
class MealCheckScheduler(private val context: Context) {
    fun update(enabled: Boolean) {
        val work = WorkManager.getInstance(context)
        if (enabled) {
            work.enqueueUniquePeriodicWork(
                NAME, ExistingPeriodicWorkPolicy.KEEP,
                PeriodicWorkRequestBuilder<MealCheckWorker>(15, TimeUnit.MINUTES).build(),
            )
        } else {
            work.cancelUniqueWork(NAME)
        }
    }

    private companion object {
        const val NAME = "meal-check"
    }
}
```

```kotlin
package com.medtrack.schedule

import java.time.DayOfWeek
import java.time.LocalDate
import java.time.LocalTime

enum class ScheduleKind(val label: String) {
    DAILY("Daily"), WEEKDAYS("Weekdays"), INTERVAL("Every N hours"), AFTER_MEAL("After meal")
}

val ScheduleRule.kind: ScheduleKind
    get() = when (this) {
        is ScheduleRule.DailyTimes -> ScheduleKind.DAILY
        is ScheduleRule.Weekdays -> ScheduleKind.WEEKDAYS
        is ScheduleRule.EveryNHours -> ScheduleKind.INTERVAL
        is ScheduleRule.AfterMeal -> ScheduleKind.AFTER_MEAL
    }

/** Switches the schedule type, carrying over the dose times where the new type has them. */
fun Schedule.withKind(kind: ScheduleKind): Schedule {
    if (rule.kind == kind) return this
    val times = when (val r = rule) {
        is ScheduleRule.DailyTimes -> r.times
        is ScheduleRule.Weekdays -> r.times
        else -> emptyList()
    }.ifEmpty { listOf(LocalTime.of(8, 0)) }
    val newRule = when (kind) {
        ScheduleKind.DAILY -> ScheduleRule.DailyTimes(times)
        ScheduleKind.WEEKDAYS -> ScheduleRule.Weekdays(
            setOf(DayOfWeek.MONDAY, DayOfWeek.TUESDAY, DayOfWeek.WEDNESDAY, DayOfWeek.THURSDAY, DayOfWeek.FRIDAY), times,
        )
        ScheduleKind.INTERVAL -> ScheduleRule.EveryNHours(8, startDate.atTime(times.min()))
        ScheduleKind.AFTER_MEAL -> ScheduleRule.AfterMeal(MealType.BREAKFAST, 0, LocalTime.of(10, 0))
    }
    return copy(rule = newRule)
}

/** Changes the start date; an interval schedule's first dose moves with it. */
fun Schedule.withStartDate(date: LocalDate): Schedule = copy(
    startDate = date,
    rule = (rule as? ScheduleRule.EveryNHours)?.let { it.copy(anchor = date.atTime(it.anchor.toLocalTime())) } ?: rule,
)
```

```kotlin
    fun update(transform: (MedicationEntity) -> MedicationEntity) =
        _state.update { it.copy(med = transform(it.med), error = null) }

    fun onNameChanged(name: String) {
        update { it.copy(genericName = name, rxcui = null) } // a typed name no longer matches a picked suggestion
        suggestJob?.cancel()
        if (name.trim().length < 3) {
            _state.update { it.copy(suggestions = emptyList()) }
            return
        }
        suggestJob = viewModelScope.launch {
            delay(400)
            val suggestions = c.lookup.suggest(name)
            _state.update { it.copy(suggestions = suggestions) }
        }
    }

    fun pickSuggestion(suggestion: Suggestion) {
        suggestJob?.cancel()
        _state.update { it.copy(suggestions = emptyList(), med = it.med.copy(genericName = suggestion.name, rxcui = suggestion.rxcui)) }
        lookUp(onlyMissing = false)
    }

    /** [onlyMissing] retries failed sources without overwriting fields that already came back OK. */
    fun lookUp(onlyMissing: Boolean) {
        val med = _state.value.med
        val name = med.genericName.trim()
        if (name.isEmpty() || _state.value.lookingUp) return
        _state.update { it.copy(lookingUp = true, suggestions = emptyList()) }
        viewModelScope.launch {
            try {
                c.lookup.lookup(name, med.rxcui) { partial ->
                    _state.update { s -> s.copy(med = s.med.applyLookup(partial, onlyMissing)) }
                }
            } finally {
                _state.update { it.copy(lookingUp = false) }
            }
        }
    }

    fun setPhoto(uri: Uri) {
        viewModelScope.launch {
            val path = try {
                c.photos.importFrom(uri)
            } catch (e: CancellationException) {
                throw e
            } catch (e: Exception) {
                _state.update { it.copy(error = "Couldn't load that photo") }
                return@launch
            }
            discardUnsavedPhoto()
            update { it.copy(photoPath = path) }
        }
    }

    fun removePhoto() {
        discardUnsavedPhoto()
        update { it.copy(photoPath = null) }
    }

    fun save() {
        val med = _state.value.med
        val error = if (med.genericName.isBlank()) "Enter the medication name" else med.schedule.validationError()
        if (error != null) {
            _state.update { it.copy(error = error) }
            return
        }
        viewModelScope.launch {
            c.medications.save(
                med.copy(
                    genericName = med.genericName.trim(),
                    brandName = med.brandName?.trim()?.ifEmpty { null },
                    doseText = med.doseText?.trim()?.ifEmpty { null },
                    notes = med.notes?.trim()?.ifEmpty { null },
                ),
            )
            if (savedPhoto != med.photoPath) c.photos.delete(savedPhoto)
            savedPhoto = med.photoPath
            _state.update { it.copy(saved = true) }
        }
    }

    private fun discardUnsavedPhoto() {
        val current = _state.value.med.photoPath
        if (current != savedPhoto) c.photos.delete(current)
    }

    override fun onCleared() {
        if (!_state.value.saved) discardUnsavedPhoto()
    }
}
```

```kotlin
/** Today's recorded doses plus the doses still to come, in time order. */
fun buildToday(meds: List<MedicationEntity>, logs: List<DoseLogEntity>, now: Instant, zone: ZoneId): List<TodayItem> {
    val today = now.atZone(zone).toLocalDate()
    val dayStart = today.atStartOfDay(zone).toInstant()
    val dayEnd = today.plusDays(1).atStartOfDay(zone).toInstant()
    val byId = meds.associateBy { it.id }
    val todayLogs = logs.filter { it.dueAt >= dayStart && it.dueAt < dayEnd }

    val recorded = todayLogs.mapNotNull { log ->
        byId[log.medicationId]?.let { TodayItem("log-${log.id}", log.id, it, log.dueAt, log.status, log.snoozedUntil, null) }
    }
    val loggedKeys = todayLogs.map { it.medicationId to it.dueAt }.toSet()
    val handledToday = todayLogs.map { it.medicationId }.toSet()

    val upcoming = meds.filter { it.active }.flatMap { med ->
        val rule = med.schedule.rule as? ScheduleRule.AfterMeal
        val skip = if (rule != null && med.id in handledToday) setOf(today) else emptySet()
        dosesBetween(med.schedule, now, dayEnd.minusMillis(1), zone, skip)
            .filter { (med.id to it) !in loggedKeys }
            .map { due ->
                TodayItem("up-${med.id}-${due.toEpochMilli()}", null, med, due, null, null, rule?.let { "After ${mealName(it.meal)}" })
            }
    }
    return (recorded + upcoming).sortedBy { it.dueAt }
}
```
